# MCP Platform Registration Plan

The goal is to make MCP4RS discoverable to developers, agents, and
MCP-compatible clients.

## Target Platforms

| Platform | Link | Purpose |
| --- | --- | --- |
| Official MCP Registry | https://registry.modelcontextprotocol.io/ | Canonical MCP server metadata registry. |
| GitHub MCP Registry | https://github.com/mcp | GitHub-native MCP discovery. |
| Glama | https://glama.ai/mcp/servers | MCP server discovery and validation. |
| Smithery | https://smithery.ai/servers | MCP server directory and agent connection surface. |
| PulseMCP | https://www.pulsemcp.com/servers | MCP ecosystem tracking and directory. |
| MCP.so | https://mcp.so/ | Broad MCP marketplace and directory. |
| Awesome MCP Servers | https://github.com/appcypher/awesome-mcp-servers | Community list for MCP servers. |

## Suggested Listing Description

```text
MCP4RS Open Earth is an open remote-sensing MCP server for discovering,
analyzing, and explaining satellite data from open Earth observation sources.
It provides MCP-compatible tools, a Gradio demonstration app, reproducible
media-gallery workflows, and provenance-aware dataset outputs for education,
research, and agentic geospatial workflows.
```
